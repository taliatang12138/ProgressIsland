# 0.1.7 · 2026-10-26

- 设置页新增“开机自启动”开关，保存后在登录当前 Windows 账号时自动显示任务岛；可随时取消，不需要管理员权限。
- 只维护当前用户的 `ProgressIsland` 启动项，支持空格与中文程序路径；启用后从新位置打开程序会更新路径，重复设置不添加重复项。
- 登录自启动遇到已运行的任务岛时静默退出，不弹出重复启动提示。预览和界面自检不会改写系统启动项。
- 保留 0.1.6 的四边停靠与悬停稳定性修复。

# 0.1.6 · 2026-10-23

- 修复鼠标静止悬停时反复展开 / 收起：任务条带较长时，展开面板沿停靠边缘调整位置，保持悬停点位于面板内，不改写保存的停靠位置。
- 使用鼠标实际屏幕坐标判断进入 / 离开；动画和控件显隐产生的 MouseLeave 不再误触发收起。
- 动画期间保留进入区域，动画结束后只使用实际面板范围，真正移开后正常收起。
- 保持固定、右键菜单和对话框的展开行为；按 Escape 收起后需移开并重新悬停才会再展开。

# 0.1.5 · 2026-10-22

- 将闲置时间选择移到展开主界面，支持分钟 / 小时 / 天 / 周的预设和自定义，立即重新分组并自动保存；默认保持一周。
- 结束记录明确标为历史，显示过往总数与待确认数，避免被误解为当前任务数量。
- Python 进程显示实际脚本或模块名，支持中文和空格路径；内联代码、标准输入和交互会话各有明确描述。
- 自动发现 Windows 终端中的外部命令，显示 npm、dotnet、Node、Python 等命令 / 脚本名称，合并子进程，排除空闲 shell 与非交互代理工具链。
- 外部命令退出标记为结果未验证并待确认；从岛启动的命令继续使用退出码判定结果。
- 后台读取名称，限制并发与超时；保护用户自定义标题，迟到的名称查询不会复活已移除任务。
- 设置页保存不再把分钟 / 小时阈值舍入为整天；预览与界面自检不写入用户设置。

# 0.1.4 · 2026-10-22

- 闲置阈值改为一周无新活动，设置以天为单位，范围 1–365 天；近期暂停或等待的任务也留在当前任务。
- 默认当前任务汇总所有进行中的任务和尚未确认的结束结果。
- 收起状态为每个任务保留独立条目：上下边缘横向排列，左右边缘竖向排列；自动按任务数量调整尺寸，并限制在工作区内，超出时可滚动。
- 结束条目显示紫点及“待确认”；点击结束条目或展开后的“确认”将其移出当前列表，保留历史。标记未读可恢复。
- 闲置入口放在横向岛和展开控制栏最右侧，竖向岛末尾。
- 取消最近 60 个会话采集和列表前 50 项的限制，避免遗漏进行中任务和未确认结果。

# 0.1.3 · 2026-10-22

- 新增“闲置”分组，与正在处理和已结束任务分别展示；运行中数量、收起状态的标题及进度排除闲置任务。
- 默认 10 分钟无新活动进入闲置，可在设置中输入 1–1440 分钟；暂停和等待中的任务也单列。
- Codex 使用当前轮次活动元数据和会话文件修改时间，长期遗留的 `inProgress` 不再被持续视为正在处理。
- 闲置只影响展示，不篡改任务结果；新活动自动恢复到运行中，闲置卡片不显示忙碌动画。
- 区分采样时间与工作活动时间，重复刷新、相同命令结果和已读操作不会使旧任务重新活跃。
- 普通日志和命令的非进度输出也可刷新活动时间；脚本心跳及计算活动保留正常监控。

# 0.1.2 · 2026-10-22

- 接入本机 Codex 最近会话：最新轮次运行、结束、失败与中断；同一会话新一轮可重新进入运行中。
- 界面划分“运行中 / 运行结束”，卡片、横向岛和竖向岛显示紫色未读点及数量。
- 右键标记为未读 / 已读；手动标记跨重启保留，不被旧的自动快照覆盖。
- 点击“打开会话”通过 Codex 深链接跳转并标记已读；悬停展开保持未读。
- 同步 Codex 本机查看记录；查看正在运行的轮次不会提前消耗之后的新结果。
- 会话采集使用后台只读 SQLite 和状态元数据，无第三方依赖，不调用模型。
- 设置可关闭 Codex 显示；移除或清空历史不会在下一次采集立即恢复相同卡片。

- 四条边缘自动吸附：上 / 下横向，左 / 右为真正竖向布局。
- 悬停向内展开、离开收起；记住屏幕及沿边缘的位置。

- GUI 进度读取改用低优先级可复用进程，并保留超时隔离；鼠标悬停 / 拖动时暂缓新查询。
